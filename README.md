# Web Application Vulnerability Scan using OWASP ZAP
# Objective
The Objective of this exercise was to perform a basic vulnerability assessment on a web application using OWASP ZAP in order to identify potential security weaknesses and misconfiguration 
# Tools used
-OWASP ZAP (Zed Attack Proxy)
# Target
- Juice shop
# Methodology
1.Installed and Launched OWASP ZAP
2.Configured the browser to route traffic through the OWASP ZAP Proxy
3.Accessed the target website through the broswer
4.Allowed OWASP ZAP to automatically scan the web application
5.Observed Alerts and Security findings generated by the scanner
# Scan Type
- Automated vulnerability scan
# Findings
The scan identified several informational and low-risk issues including:
1.Missing Security Headers: Some HTTP Security headers were not present in the response
2.Server information Disclosure: The web server revealed information about the technology used 
3. Cookie Security Attributes: Some cookies did not include recommended security activities 
# Risk levels
Most findings were categorized as:
-Informational
- Low Risk
# Security Insight
OWASP ZAP helps security testers identify common web vulnerabilities such as:
-Cross-Site Scripting (XSS)
-SQL injection
-Security misconfiguration
-Missing security headers
Automated scanners like OWASP ZAP are useful for quickly identifying potential issues,but manual testing is still required to validate vulnerabilities 
# Conclusion
This exercise provided practical experience using OWASP ZAP to scan a web application for potential vulnerabilities
