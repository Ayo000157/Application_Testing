# Nikto Web Vulnerability Scan
This repository contains a Nikto web vulnerability scan report conducted on the OWASP juice shop application
# Overview
Nikto is an open source web server scanner that checks for:
-Outdated server software
-Misconfigurations
-Security Headers
-Potentially Dangerous files and scripts
# Scan Details
-Target:Juice Shop
-Tool:Nikto
-Scan Type: Web Server Vulnerability assessment
